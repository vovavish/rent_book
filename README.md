
**Литэра** — онлайн-платформа для аренды книг.  
Пользователи могут находить литературу, оставлять заявки на аренду, а владельцы книг — управлять этими заявками.  

---

## 🚀 Технологии

- **Фронтенд:** React + Vite + MobX  
- **Бэкенд:** NestJS + Prisma + PostgreSQL  

---

## ⚙️ Функционал

- 🔑 Регистрация и авторизация пользователей  
- 📚 Поиск и просмотр книг  
- 📄 Заявки на аренду книг  
- 🔄 Система статусов аренды (новая, в процессе, завершена и т.д.)  
- 📨 Управление заявками владельцем  
- 🛠 Поддержка пользователей  
- 🚩 Жалобы на издания  
- 👥 Роли:
  - Пользователь
  - Администратор
